# Picker Gallery Example

A comprehensive demonstration of WaterUI's picker components.

## Components Demonstrated

### DatePicker
- Date-only selection
- Time-only selection (hour and minute)
- Combined date and time picker
- Date range constraints

### ColorPicker
- Standard RGB color selection
- Alpha channel support
- HDR color support (iOS 14+)

### FilePicker
- Single file selection
- Multiple file selection
- File import mode

## Running

```bash
# iOS Simulator
water run --platform ios

# Android Emulator
water run --platform android
```

## Features

- Reactive bindings for all picker values
- Live preview of selected values
- Platform-native picker UI
